DOSBTS — SIRI VOICE LOGGING_

Build 94+ · Insulin & Meals, hands-free

1. Setup

  1. Install build 94 (or later) from TestFlight.
  2. Open DOSBTS once after upgrading — this registers the shortcuts with iOS.
  3. Done. No permission prompts, no Shortcuts app required.
Siri, Spotlight, and the Shortcuts app all pick up the intents automatically.

2. Where Siri lives

  • SIRI "Hey Siri" or side-button
  • SPOTLIGHT Swipe down on Home Screen → type "log insulin"
  • SHORTCUTS Build a 1-tap home-screen tile with preset values

3. Insulin — trigger phrases

  • "Hey Siri, log insulin in DOSBTS"
  • "Hey Siri, log a dose in DOSBTS"
  • "Hey Siri, log a basal in DOSBTS" | swap in snack, meal, or correction
  • "Hey Siri, add insulin to DOSBTS"

FLOW

01 YOU Trigger phrase
"Log a basal in DOSBTS"
02 SIRI Asks for units
"How many units?"
03 YOU Reply with number
"Twenty" / "Two point five"
04 SIRI Confirms & logs
"Logged 20 units of basal."
Defaults: type = snack bolus. Basal entries get a 24h ENDS automatically.
Numeric values can't ride in the trigger phrase — Apple only allows enum/entity params there. Siri asks for the number as a follow-up.

4. Meals — trigger phrases

  • "Hey Siri, log a meal in DOSBTS"
  • "Hey Siri, log food in DOSBTS"
  • "Hey Siri, log carbs in DOSBTS"
  • "Hey Siri, add a meal to DOSBTS"

FLOW

01 YOU Trigger phrase
"Log a meal in DOSBTS"
02 SIRI Asks for carbs
"How many grams?"
03 YOU Reply
"Forty-five" / "Thirty grams"
04 SIRI Confirms & logs
"Logged 45 grams: meal."
Default description = "meal". Siri can also ask for a label ("toast", "apple") if you want to keep history readable.

5. Tips

  • Both intents run in the background — Siri confirms by voice without opening the app.
  • Chart markers show up next time DOSBTS is foregrounded; widgets refresh right away.
  • Decimals work: "two point five" → 2.5 U.
  • For a 1-tap preset, open Shortcuts.app, find "DOSBTS — Log insulin", fill in fixed values, add to Home Screen.

6. Limits

  • Trigger phrase can't include numbers — Siri prompts for them after.
  • Insulin type is one of: meal / snack / correction / basal.
  • Edits, deletes, and rich entries (photo, barcode) still go through the app.
  • Critically: this is for recording, not dosing decisions.
